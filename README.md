MyTimelines is: 
- a chronology of mainly Wikipedia pages on (ancient) civilizations, kingdoms, battles/wars, key actors and archeological sites
- a number of graphical timelines created with The TimelineProject (https://sourceforge.net/projects/thetimelineproj)
- a collection of geographical/historical maps
- a continuous work in progress
- in English
- looking great on a 32-inch display
- created for me, shared with you
